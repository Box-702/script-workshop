# 万物皆插件 — 插件系统设计

## 设计理念

参考 ZCode Skill + CrewAI Tool + VS Code Extension 的优点，结合项目 Python-first 的特点：

- **声明式发现**：插件放在约定目录，系统自动扫描
- **零代码入门**：YAML manifest 即可定义简单工具
- **代码扩展**：Python 类可实现复杂逻辑
- **热加载**：插件增删无需重启服务

## 插件目录结构

```
~/.script-workshop/plugins/          # 用户级插件
<project>/.plugins/                   # 项目级插件
app/plugins/builtin/                  # 内置插件

每个插件是一个目录：
my-plugin/
  plugin.yaml           # 插件清单（必需）
  tools.py              # 工具定义（可选）
  agents.py             # Agent 定义（可选）
  README.md             # 说明文档（可选）
```

## plugin.yaml 清单格式

```yaml
name: my-research-tool
version: "1.0"
description: 联网调研工具，搜索并汇总资料
author: user
type: tool                    # tool | agent | skill

# 工具定义（type=tool 时）
tools:
  - name: research_topic
    description: 对指定主题进行联网调研，返回结构化报告
    parameters:
      topic:
        type: string
        description: 调研主题
        required: true
      depth:
        type: string
        description: 调研深度
        enum: [basic, deep]
        default: basic

# MCP Server（可选，连接外部 MCP 服务）
mcp:
  command: npx
  args: ["-y", "@my-org/mcp-server"]
  env:
    API_KEY: "${MY_API_KEY}"

# 配置项（用户可在设置界面填写）
config:
  api_key:
    type: string
    sensitive: true
    description: 第三方 API Key
```

## 核心模块

### app/plugin/loader.py — 插件加载器

```python
class PluginLoader:
    def discover() -> list[Plugin]    # 扫描所有插件目录
    def load(plugin) -> Plugin        # 加载单个插件
    def reload(plugin)                # 热重载
```

扫描顺序（优先级从高到低）：
1. `<project>/.plugins/`
2. `~/.script-workshop/plugins/`
3. `app/plugins/builtin/`

### app/plugin/registry.py — 插件注册表

```python
class PluginRegistry:
    def register(plugin)              # 注册插件
    def get_tools() -> list[BaseTool] # 获取所有插件工具
    def get_agents() -> list          # 获取所有插件 Agent
    def list_plugins() -> list[dict]  # 列出所有插件
    def enable(name) / disable(name)  # 启用/禁用
```

### app/plugin/base.py — 插件基类

```python
class Plugin:
    name: str
    version: str
    description: str
    tools: list[BaseTool]       # 插件提供的工具
    agents: list[CrewAgent]     # 插件提供的 Agent
    mcp_server: MCPServer | None

class MCPServer:
    command: str
    args: list[str]
    env: dict[str, str]
    async def list_tools() -> list[dict]
    async def call_tool(name, args) -> Any
```

### app/plugin/mcp.py — MCP 协议适配

```python
class MCPAdapter:
    async def connect(server)         # 启动 MCP server 进程
    async def list_tools(server) -> list[dict]
    async def call_tool(server, name, args) -> Any
    async def disconnect(server)
```

MCP 工具自动转为 LangChain Tool：
```python
def mcp_tool_to_langchain(mcp_tool_def, server) -> BaseTool
```

## 集成点

### 1. 工具注册（tools.py / chat.py）

```python
# build_tools() 中追加插件工具
def build_tools(...):
    builtin_tools = [...]
    plugin_tools = get_plugin_registry().get_tools(
        context={"script": script, "project": project, "store": store}
    )
    return builtin_tools + plugin_tools
```

### 2. 单例管理（deps.py）

```python
@lru_cache
def plugin_registry() -> PluginRegistry:
    registry = PluginRegistry()
    loader = PluginLoader()
    for plugin in loader.discover():
        registry.register(plugin)
    return registry
```

### 3. 设置界面（前端）

新增「插件」tab：
- 已安装插件列表（启用/禁用开关）
- 插件详情（描述、工具清单、配置项）
- 安装新插件（输入目录路径或 Git URL）
- MCP Server 配置

### 4. API 端点

```
GET  /api/plugins                # 列出所有插件
POST /api/plugins/install        # 安装插件
POST /api/plugins/{name}/enable  # 启用
POST /api/plugins/{name}/disable # 禁用
DELETE /api/plugins/{name}       # 卸载
GET  /api/plugins/{name}/tools   # 查看插件工具
```

## 示例：用户自定义工具

用户在 `~/.script-workshop/plugins/my-tool/` 下创建：

**plugin.yaml:**
```yaml
name: character-analyzer
version: "1.0"
description: 分析角色关系网络，生成关系图谱数据
type: tool
tools:
  - name: analyze_relationships
    description: 分析剧本中角色之间的关系，返回关系网络数据
    parameters:
      project_id:
        type: string
        description: 项目 ID
        required: true
```

**tools.py:**
```python
from langchain_core.tools import tool

@tool
def analyze_relationships(project_id: str) -> str:
    """分析剧本中角色之间的关系，返回关系网络数据。"""
    # 自定义逻辑
    return "角色关系分析结果..."
```

系统自动发现、注册，Agent 即可调用。
