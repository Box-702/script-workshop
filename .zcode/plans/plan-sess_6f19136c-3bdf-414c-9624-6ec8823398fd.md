# 聊天区与工作区分离方案

## 目标
1. 聊天与项目完全解耦 — 用户可以随时新建独立聊天
2. 工作区作为左侧文件树 — 映射本地文件夹

## 后端改动

### 1. 全局对话支持
- `store.py`: `Conversation.project_id` 改为 nullable
- `api.py`: 新增 `POST /api/conversations`（不绑定项目）
- `api.py`: 新增 `GET /api/conversations`（列出全局对话）

### 2. 聊天接口适配
- `chat.py`: `chat_once`/`chat_stream` 的 `project_id` 可为 null
- 无 project_id 时，工具只保留通用能力（问答、记忆），不调项目相关工具

## 前端改动

### 3. 左栏重构成两个区块
- `ProjectTree.vue` → 拆成 `ChatList.vue`（聊天列表）+ `WorkspaceTree.vue`（文件树）
- `ChatList.vue`: 显示全局对话 + 项目内对话，带新建按钮
- `WorkspaceTree.vue`: 显示 workspace 目录结构

### 4. store/app.js 改动
- 新增 `store.globalConvs` — 全局对话列表
- 新增 `store.workspaceTree` — 文件树数据
- `selectConversation` 支持无 pid 的全局对话
- `sendMessage` 在无 pid 时只发通用消息

### 5. 中间聊天区适配
- 无项目时显示通用 WelcomeHero（不需要选项目才能开聊）
- 聊天正常工作，只是不带项目上下文

## 改动文件清单
